#  Myth Web Project — Interactive Mythology Platform

An interactive and modern web application exploring Greek, Egyptian, and Norse mythologies. The platform presents gods, legends, artifacts, and ancient symbols through a dynamic, content-driven web experience.

##  Key Features
- **Mythology Catalog & Content Discovery:** Categorized exploration of pantheons, deities, and mythological sagas.
- **User Authentication & Authorization:** Implemented with ASP.NET Core Identity for secure account creation, login, and profile access.
- **Responsive Architecture:** Clean and responsive UI supporting seamless browsing across devices.
- **MVC Architecture:** Separation of concerns using Model-View-Controller design patterns.

##  Tech Stack & Architecture
- **Framework:** ASP.NET Core MVC (.NET)
- **Language:** C#, HTML5, CSS3, JavaScript
- **Database & ORM:** Entity Framework Core, SQL Server / MySQL (Code-First Migrations)
- **Security:** ASP.NET Core Identity

##  Project Structure
- `Controllers/` — Handles routing logic and UI interactions.
- `Models/` — Entity models representing mythological records and database context.
- `Views/` — Razor views for responsive front-end rendering.
- `Areas/Identity/` — Scaffolding for user authentication workflows.
- `Data/` & `Migrations/` — Database schema management and migrations.
